# Moire Media — landing page

Static site. Upload the whole folder to any static host (Netlify, Vercel, Cloudflare Pages, GitHub Pages, S3).

Files
- index.html — the page
- support.js — runtime that renders the page (required)
- stickman.js — the pencil stick figure (required; loaded as a module, so serve over http(s), not file://)
- assets/moire-logo.png — logo

Fonts load from Google Fonts (Archivo, Archivo Black). No build step.
